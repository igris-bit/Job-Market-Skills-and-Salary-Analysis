# Dataset Description

This dataset contains information about job opportunities in India.

## CSV Columns

1. **Job_Role:** Describes the job title or position offered by a company.

2. **Company:** Contains the name of the company offering the job.

3. **Location:** Specifies the city or place where the job is available.

4. **Job Experience:** Describes the work experience required for a particular job.

5. **Skills/Description:** Contains the required technical skills, qualifications, and responsibilities for the job.

## Purpose

This dataset helps analyze job roles, companies, locations, experience requirements, and skills needed in the job market.
