# Technical Terms Glossary

Here are simple definitions and examples for key software and data terminology:

1. Dataset
Definition: A structured collection of related data organized into rows and columns, similar to a digital spreadsheet or table.
Example: A table containing student records with columns for *Name*, *Age*, and *Grade*.

2. CSV (Comma-Separated Values)
Definition: A plain text file format used to store tabular data where each data value is separated by a comma.
Example: A file named `students.csv` containing text formatted as: `Name,Age,Grade`.

3. Pandas
Definition: A popular Python library used for analyzing, cleaning, manipulating, and processing data efficiently.
Example: Writing code using Pandas to load a dataset and instantly calculate the average test score.

4. Flask
Definition: A lightweight web framework for Python that helps developers build web applications and APIs quickly and easily.
Example: Creating a simple backend web server in Python using Flask that responds with "Hello World!".

5. API (Application Programming Interface)
Definition: A set of rules and tools that allows two different software applications to communicate and share data with each other.
Example:  A weather app on your smartphone using a weather service's API to show today's live temperature.

6. Endpoint
Definition: A specific web address (URL) provided by an API where an application can send requests to fetch or send specific data.
Example: `https://api.weather.com/v1/current-temperature` is an endpoint to retrieve weather data.

7. Frontend
Definition: The user-facing side of a software application or website—everything that users see, click, and interact with visually.
Example: The login screen of an application with buttons, input fields, images, and styling.

8. Backend
Definition: The server-side part of a web application that runs behind the scenes to process logic, handle databases, and serve data to the frontend.
Example: The server system that verifies your password when you log into a website and fetches your profile info from the database.
